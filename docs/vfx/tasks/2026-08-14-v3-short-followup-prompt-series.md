# V3-Kurzpromptserie für die Elemental Sandbox

## Ziel

Vier V3-Abstufungen für denselben Vergleich erzeugen: Jede weist im aktuell geöffneten Repository genau 20 zusätzliche VFX für dieselbe Signature Library an. Deutsch/Englisch-Paare halten den Inhalt gleich; zwischen V3.1 und V3.4 steigen Länge und Adjektivdichte. Keine Fähigkeit wird vorbenannt.

## Phasen

- [x] P1 — Beispielprompt und verbindliche Promptregeln auswerten.
- [x] P2 — Vier kurze, isoliert vergleichbare V3-Prompts schreiben.
- [x] P3 — Promptlexikon ergänzen und Dokumentation statisch abschließen.
- [x] P4 — Nutzerkorrektur: nur 20 zusätzliche VFX im selben Repository anweisen.
- [x] P5 — Deutsche und englische Paare mit vier Dichtestufen ausarbeiten.

## Entscheidungen

- Alle acht Promptkörper arbeiten ausschließlich im aktuell geöffneten Repository und erweitern dieselbe Library um genau 20 zusätzliche VFX.
- V3.1 bis V3.4 steigern bewusst Länge und Adjektivdichte; Stack, Seed und Umfang bleiben konstant.
- Innerhalb jeder Stufe sind deutsche und englische Fassung semantisch deckungsgleich, damit der Spracheinfluss beobachtbar bleibt.
- Die zentrale Datei in einem anderen Projektordner wird wegen der Arbeitsordnergrenze nicht gelesen oder verändert; die Serie liegt im zugewiesenen V20.3-Projekt.
- Reine Dokumentationsarbeit: keine Tests, Builds, Serverstarts oder Sichtprüfungen.
